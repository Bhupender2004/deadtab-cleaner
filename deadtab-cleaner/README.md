# 🕸️ DeadTab Cleaner

**DeadTab Cleaner** is a comprehensive monorepo project designed to detect, manage, and automatically archive inactive browser tabs. It features an interactive Chrome Extension, a powerful Node.js Backend with AI-powered tab summarization via Anthropic, and a beautiful React frontend dashboard.

---

## ✨ Features

### 🧩 Chrome Extension (MV3)
- **Automatic Inactivity Detection**: Intelligently detects tabs that haven't been used for a while.
- **Interactive UI Prompts**: Rather than silencing tabs without warning, it injects a non-intrusive, Shadow DOM-based popup directly into the active tab.
- **Granular Control**: Easily choose to archive all inactive tabs, close the oldest tab, or snooze the alert.

### 💻 Frontend Dashboard
- **Modern Tech Stack**: Built with React 18, TypeScript, and Vite.
- **Interactive Analytics**: Displays your browsing habits and a "Habit Score" using dynamic charts (Recharts).
- **Tab Archives & AI Notes**: View deeply archived tabs alongside intelligent summarizations and notes generated by AI.
- **State Management**: Optimized with Zustand and TanStack React Query for snappy interactions.
- **Search capabilities**: Deep dive into your archived tabs using fuzzy search powered by Fuse.js.
- **Premium UI**: Styled with Tailwind CSS for a sleek, responsive, and beautiful aesthetic.

### ⚙️ Backend API
- **Express.js Server**: Fast, reliable architecture running Node.js.
- **AI Integration**: Powered by `@anthropic-ai/sdk` to generate contextual notes on archived tab contents.
- **Robust Database**: Uses Supabase for secure data storage and authentication.
- **Background Jobs**: Leveraging Redis and BullMQ to efficiently process tab archiving and AI note generation off the main thread.
- **Security**: Secured with express-rate-limit, cors, and jsonwebtoken (JWT) authentication.

## 🏗️ Project Structure

This project is a monorepo consisting of three main environments:


## 🚀 Getting Started

### Prerequisites
Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v16+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Redis](https://redis.io/) (Required for Backend BullMQ background jobs)

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/deadtab-cleaner.git
cd deadtab-cleaner
```

### 2. Backend Setup
Navigate to the backend directory, install dependencies, and configure your environment.
```bash
cd backend
npm install
```
Create a `.env` file based on your `.env.example` in the backend directory. You will need keys for:
- Supabase (URL & Anon Key)
- Anthropic API Key
- Redis Connection URL

Run the development server:
```bash
npm run dev
```

### 3. Frontend Setup
Navigate into the frontend directory and install dependencies.
```bash
cd ../frontend
npm install
```
Create a `.env` file based on `.env.example` to point to your local API URL.
Start the Vite development server:
```bash
npm run dev
```

### 4. Extension Setup
1. Open Google Chrome.
2. Go to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked**.
5. Select the `extension/` folder from this repository.
